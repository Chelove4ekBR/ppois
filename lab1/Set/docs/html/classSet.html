Подробное описание

Класс, представляющий математическое множество.

Множество может содержать как атомарные элементы (например, символы или строки), так и другие множества, обеспечивая поддержку сложной вложенности. Класс автоматически поддерживает уникальность элементов и их сортировку (нормализацию).
